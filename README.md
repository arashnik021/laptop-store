# Laptop Store

یک فروشگاه اینترنتی لپ‌تاپ فارسی و راست‌چین، ساخته‌شده با React 18، Vite، Bootstrap 5، Context API، LocalStorage و Swiper.

## اجرای پروژه

```bash
npm install
npm start
```

پس از اجرا، Vite آدرس محلی برنامه را در ترمینال نمایش می‌دهد.

## فناوری‌ها

- React 18
- React Router DOM
- Bootstrap 5 RTL و Bootstrap Icons
- Context API
- LocalStorage
- Swiper.js
- Vazirmatn
- CSS3 با Design Tokens و طراحی Mobile First

## قابلیت‌ها

- ۳۰ محصول Mock، ۸ دسته‌بندی و ۱۰ برند
- جست‌وجو، فیلتر، مرتب‌سازی و صفحه‌بندی محصولات
- جزئیات محصول و گالری سه‌تصویری
- سبد خرید پایدار با محاسبه هزینه ارسال
- علاقه‌مندی‌های پایدار
- ورود و ثبت‌نام نمایشی با LocalStorage
- پروفایل محافظت‌شده با React Router
- Dark Mode ذخیره‌شده در مرورگر
- Hero Slider و Product Slider با Swiper
- طراحی کاملاً فارسی، RTL و Responsive
- فرم‌های اعتبارسنجی‌شده برای ورود، ثبت‌نام، تماس و خبرنامه

## حساب نمایشی

- ایمیل: `demo@laptopstore.ir`
- رمز عبور: `laptop123`

## محدودیت آگاهانه

این یک پروژه Front-End آموزشی است. پرداخت واقعی، ثبت سفارش سمت سرور، مدیریت موجودی واقعی و احراز هویت امن ندارد. داده‌های محصول، نظرات و اطلاعات تماس نمونه هستند.

## ساختار اصلی

```text
src/
├── components/  # اجزای قابل استفاده مجدد
├── contexts/    # Cart، Wishlist، Auth و Toast
├── data/        # داده‌های Mock
├── hooks/       # Hookهای سفارشی
├── pages/       # صفحات Routeها
├── routes/      # Routing و ProtectedRoute
├── styles/      # Design System و Responsive CSS
└── utils/       # قیمت، اعتبارسنجی، داده و LocalStorage
```
